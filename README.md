# Write from the Heart — Personal Letter Writing Pack

> Five AI-powered skills for writing heartfelt personal letters people will treasure.

## Skills Included

- **Love Letter Writer** — romantic letters for partners, anniversaries, and heartfelt declarations
- **Poem Writer** — original personalised poems for any occasion
- **Lyrics Writer** — original song lyrics in any style
- **Short Story Starter** — short story openings tailored to your characters and setting
- **Greeting Card Maker** — personalised greeting card images for any occasion

## Requirements

- [Openclaw](https://openclaw.ai) — AI assistant that runs these skills

## Usage

1. Open Openclaw
2. Load the SKILL.md file for the skill you want to use
3. Follow the steps — Openclaw will ask for your details and produce the file
